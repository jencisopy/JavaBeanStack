# JavaBeanStack
Framework para construcción de aplicaciones **Jakarta EE 11** (rama `master`; la rama `1.5.x` mantiene la línea Java EE 8)

## AWS Stack ##
Integración con **Amazon Web Services (S3)**.

- **`S3Manager`** — operaciones sobre buckets y objetos: crear/listar/eliminar buckets, listar/copiar/eliminar objetos.
- **`S3Util`** — utilidades de apoyo para S3.

Módulo independiente, fuera de la cadena de dependencias principal del framework.
